## 実装仕様

### handlePokemonSelect関数（詳細取得・表示処理）

#### 実装の背景と目的
現在のhandlePokemonSelect関数は空の状態です。この関数を実装して、
実際にAPIからポケモンの詳細データを取得し、メイン画面に美しく表示できるようにします。

#### 関数の設計要件
- useCallbackでメモ化してレンダリングを最適化
- 依存配列は空配列 [] を維持（関数の再作成を防ぐ）
- パラメータ: pokemonUrl（string型）
- エラーハンドリングパターン：try-catch-finally構文を使用

#### 実装手順

**Step 1: ローディング状態の管理**
ポケモンをクリックした瞬間にローディング状態を開始し、
ユーザーに処理中であることを明確に示します。
- setLoadingDetail(true)でローディング開始
- メイン表示エリアにローディングスピナーが表示される

**Step 2: 選択状態の保存**
どのポケモンが選択されているかをUIで明示するため、
選択されたポケモンのURLを状態として保存します。
- setSelectedPokemonUrl(pokemonUrl)で選択状態を保存
- リスト内で選択中のポケモンがハイライト表示される

**Step 3: URLからポケモンIDを抽出**
PokeAPIでは各ポケモンに数値IDが割り当てられています。
URLからこのIDを抽出する必要があります。
- pokemonService.extractIdFromResourceUrlを使用
- URLの例: "https://pokeapi.co/api/v2/pokemon/25/" → ID: 25
- エラーハンドリング: if (!pokemonId) throw new Error('Invalid Pokemon URL')

**Step 4: 詳細データの取得**
ポケモンサービスを使用して、基本データと日本語名を一度に取得します。
- pokemonService.getPokemonDetailWithJapaneseNameを使用
- このメソッドは内部で以下を自動実行:
  - 基本的な詳細データ（タイプ、ステータス、画像など）
  - 日本語名データ
  - 両方のデータを結合した完全なオブジェクト

**Step 5: データの保存とUI更新**
取得した詳細データを状態に保存し、UIが自動的に更新されるようにします。
- setSelectedPokemon(pokemonDetail)でデータを保存
- Reactの状態管理により、メイン表示エリアのポケモン画像と名前が自動更新される

#### エラー処理とユーザー体験

**エラーケースの対応:**
以下のような問題が発生してもアプリケーションは継続動作:
- 不正なURL形式、ネットワーク接続の問題、APIサーバーのダウン、データの形式エラー
- console.error('ポケモン詳細の取得に失敗しました:', error)でエラーログを出力

**確実なローディング終了:**
成功・失敗に関わらず、必ずローディング状態を解除し、UIが固まることを防ぎます。
- finallyブロックでsetLoadingDetail(false)

#### 実装時の重要なポイント

**非同期処理のパターン:**
```
async (pokemonUrl: string) => {
  try {
    // 成功時の処理フロー
  } catch (error) {
    // エラー時の処理フロー
  } finally {
    // 必ず実行される後処理
  }
}
```

**状態更新の順序:**
1. ローディング開始 → ユーザーに処理開始を通知
2. 選択状態保存 → UIでハイライト表示
3. データ取得 → APIからの情報取得
4. データ保存 → UIに反映
5. ローディング終了 → ユーザーに処理完了を通知

## 使用するサービスと関数

**pokemonService:**
- **extractIdFromResourceUrl**: URLから数値IDを抽出
- **getPokemonDetailWithJapaneseName**: 詳細データと日本語名を一括取得

**状態管理関数:**
- **setLoadingDetail**: 詳細取得のローディング状態管理
- **setSelectedPokemonUrl**: 選択されたポケモンのURL管理
- **setSelectedPokemon**: 詳細データの管理
