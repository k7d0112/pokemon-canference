## 実装仕様

### Part 1: 検索フィルタリング処理（src/app/page.tsx）

#### 実装の背景
現在は検索機能が実装されていません。日本語名を含む高度な検索フィルタリング機能を実装します。

#### useEffectの実装要件
**依存配列:** [allLoadedPokemon, searchTerm]

**処理の条件:**
- allLoadedPokemon配列に日本語名付きデータが存在する場合のみ実行
- 検索語句（searchTerm）の有無で分岐処理

#### フィルタリングロジックの実装

**1. データ存在確認**
まず、日本語名を含むポケモンデータが準備されているかを確認します。
- allLoadedPokemon.length > 0 の場合のみ処理実行

**2. 検索語句による分岐処理**
検索語句が入力されているかどうかで処理を分けます：

**検索語句がある場合:**
- allLoadedPokemon配列をfilterメソッドでフィルタリング
- 各ポケモンに対してマッチング条件をチェック

**検索語句がない場合:**
- 全てのポケモンを表示（allLoadedPokemon配列をそのまま使用）

**3. マッチング条件の実装**
各ポケモンが検索条件に合致するかを判定：

**英語名でのマッチング:**
- pokemon.name（英語名）を小文字に変換
- 検索語句も小文字に変換、includes()メソッドで部分一致を判定

**日本語名でのマッチング:**
- pokemon.japaneseName（日本語名）を小文字に変換
- オプショナルチェーン（?.）で安全にアクセス
- includes()メソッドで部分一致を判定

**判定結果:**
- 英語名OR日本語名のどちらかがマッチすればtrue

**4. 結果の保存**
フィルタリング結果を状態に保存：
- setFilteredPokemon()で結果を状態に保存
- UIが自動的に更新され、検索結果が表示される

### Part 2: 検索モーダルUI（src/components/SearchModal.tsx）

#### 検索モーダルの役割
ユーザーが検索語句を入力し、実行するためのインターフェース。
直感的な操作で素早く目的のポケモンを見つけられるようにします。

#### 実装する関数（3つ）

**1. handleSearch関数（検索実行処理）**

**機能の目的:** 検索ボタンをクリックした時に実行される中心的な処理

**実装要件:**
- 入力された検索語句の前後の空白を削除（trim()）
- 空の検索語句の場合は何もしない
- 有効な検索語句がある場合のみ検索実行
- 検索実行後は入力欄をクリア、モーダルを自動的に閉じる

**処理の流れ:**
1. searchTerm.trim()で前後の空白を削除
2. 空文字でない場合のみ以下を実行:
   - onSearch()で親コンポーネントに検索語句を渡す
   - setSearchTerm("")で入力欄をクリア
   - onOpenChange(false)でモーダルを閉じる

**2. handleKeyDown関数（キーボード処理）**

**機能の目的:** Enterキーを押すだけで検索を実行できる便利機能

**実装要件:**
- キーボードイベントを受け取り、Enterキーを判定
- Enterキーが押された場合にhandleSearch()を呼び出す

**処理の詳細:**
- event.key === "Enter" でEnterキーを判定
- 判定が真の場合、handleSearch()を実行

**3. handleClose関数（キャンセル処理）**

**機能の目的:** 検索をキャンセルしてモーダルを閉じる処理

**実装要件:**
- 入力途中の内容を破棄、モーダルを閉じる、検索実行は行わない

**処理の内容:**
- setSearchTerm("")で入力内容をクリア
- onOpenChange(false)でモーダルを閉じる

#### UI実装

**入力フィールドの実装:**
- プレースホルダーで使い方をガイド（「ポケモン名を入力...」）
- 制御コンポーネントパターン（value + onChange）
- Enterキーのイベント処理接続
- 自動フォーカスでユーザビリティ向上

**ボタン群の実装:**
- キャンセルボタン: アウトラインスタイル、Xアイコン、handleCloseで処理
- 検索ボタン: メインアクション、検索アイコン、空入力時は無効化、handleSearchで処理

## 実装時の技術的ポイント

### 文字列処理
- **trim()**: 前後の空白削除で正確な検索
- **toLowerCase()**: 大文字小文字を統一
- **includes()**: 部分一致の判定

### 配列処理
- **filter()**: 条件に合う要素を抽出

### 条件分岐
- **三項演算子**: 簡潔な条件分岐
- **論理演算子**: 複数条件の組み合わせ（OR演算子）
- **オプショナルチェーン**: 安全なプロパティアクセス

### React パターン
- **制御コンポーネント**: value + onChange
- **useEffect**: 状態変化の監視
- **条件付きレンダリング**: UI状態の切り替え

## 期待される動作の流れ

### 検索実行の流れ
1. ユーザーがヘッダーの検索アイコンをクリック
2. 検索モーダルが表示され、入力欄に自動フォーカス
3. ポケモン名を入力（例: 「ピカ」「pika」「フシギ」など）
4. Enterキーまたは検索ボタンで検索実行
5. モーダルが自動的に閉じる
6. リストが検索結果にフィルタリングされる

### 検索解除の流れ
1. リスト上部の「クリア」ボタンをクリック
2. フィルターが解除され、全ポケモンが表示される
